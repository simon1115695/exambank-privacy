# ExamBank — Privacy Policy

Hosts the privacy policy page for the **ExamBank** iOS app, as required by
App Store Connect.

Published at <https://simon1115695.github.io/exambank-privacy/>

The source of truth is `docs/index.html` in the app repository; this repo
exists only because GitHub Pages cannot publish from a private repo on a
free plan. Update there first, then copy the file here.
